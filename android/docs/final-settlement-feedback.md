# 最终结算观察与宝箱确认

结算阶段只接受动作锁空闲、截图晚于动作实际完成时间且截图与当前时钟都经过落地间隔的观察。已接受的截图时间须严格递增；不满足门禁的观察不修改阶段、稳定帧或重试计数。重新取得动作锁后再次校验新鲜性和当前结果归属。

## 宝箱结果

- 宝箱结果候选建立有界等待期限，不以低置信页面或缺失按钮作为点击依据。尚未确认宝箱时，两张新的可信分数结果可交还分数关闭重试；已确认宝箱结果不因旧分数页或地图抖动回退。
- 自动确认要求页面、标题、按钮均达到可信门槛，存在真实按钮矩形，并取得两张严格递增的可信观察。确认由绑定当前会话的执行器执行。
- 只对 `Executed` 增加宝箱确认次数并记录实际完成时间，最多三次；每次完成后至少两秒才能再次确认。暂停、过期会话、预演和拒绝不消耗真实执行预算。
- 结果候选和反馈总等待期限为十五秒，未知页与地图抖动不补充预算。停止时保留未完成状态，不记作通关。
- 首张可信最终道具页在预算边界提供一次最多一点五秒的稳定确认窗口，不因单帧候选无限续期；连续两张可信道具页才进入最终道具关闭流程。

## 通关依据

宝箱确认执行成功不等于通关。最终道具关闭实际完成后，仍须动作落地间隔之外两张可信、严格递增的闲置黎明界主页观察；低置信主页及其他页面重置可信主页计数。缺少可靠离页反馈时有限等待后停止，不提前发布通关。

离线回归使用合成观察及真实会话绑定执行器，覆盖旧截图、执行中截图、候选信任、分数重试、页面抖动、确认预算、最终道具边界和主页信任。离线验证不替代实际 Android 截图、视觉引擎及手势的实机复测。
