# 商店商品类别确认与库存覆盖

所有真实商品先经过标题类别确认，明确的印记标题会清除遗物候选。完整的已知职能印记标题允许局部 OCR 容错：异体字先归一，单字替换、「型」后多出的一字以及职能名丢掉首字均按已知标题校验；丢首字仅在剩余片段唯一指向一个职能时接受。随机印记与选择印记是独立类型，不从共享图标推断具体职能。遗物图标匹配门槛保持不变。

同一标题画面最多使用三种读取方式：原裁剪放大两倍、放大三倍、扩大上下边界后放大三倍。每轮等待窗口为三秒，每种方式最多提交一次。确认成功的标题按像素指纹缓存，标题变化或离开商店后失效；调度器拒绝旧画面回调。商品价格来自有效资源及冻结的账号折扣，稀有度来自遗物资源，不由标题猜测。

印记必须连职能一起核实才算确认。只读出印记但职能缺失时继续换裁剪读取，三种方式都失败则标为 `EXHAUSTED`。预算路径把该状态保留为异常并有限等待；商品售罄与正常购物完成只按实际核实结果判定，购买只针对身份与价格均已核实的商品。

完整扫描证明六个物理位置，其中可以包含真实商品与明确空位。空位只由保守的亮色均匀卡片内部证据确认；按钮未识别、被遮挡或未知状态不能代替空位证据。空位跳过标题 OCR，直接按空位计入库存覆盖。A/B 视图要求几何一致、实际占用列位移一致以及两次新稳定帧。

同店同轮成功购买至少三件任意类型商品后，可启用剩余库存单屏模式。成功交易须回执核验且持有提交完成，按交易键去重。已购槽位从该轮购买意图与已提交回执关联取得，缺失、重复或不明确的槽位不授予单屏资格。售罄卡片可以留在原位：已购槽位不重复读取标题，也不计入空位或禁用商品；新帧若显示该槽位仍可购买，撤销单屏资格。其余商品须在当前视口内完整核实身份、价格和按钮，并由两张独立稳定帧证明覆盖；剩余商品不重新编号，也不限于第一排。视口不合适时进行必要的向顶定位。真正全空库存仍须执行向顶动作后核实两帧全空证据。

成功刷新或切换商店重置库存轮次；购买、弹窗及截图缓存失效不清零成功购买总数。已购集合改变会撤销旧图覆盖并推进截图代次。钱包像素变化只要求重验余额，实际金额矛盾才撤销库存连续性；单帧过渡背景不算离店，新鲜稳定且无商店遮挡、无购物执行中的离店页才撤销资格。恢复、人工接管、额外商品或缺位矛盾回到完整扫描；无法证明库存覆盖时继续等待，直到证据齐备。

离线回归覆盖商品类别与职能标题容错、资源价格、稀有度阶段规则、随机职能偏好、真实空位、剩余实际位置、缓存失效、刷新重置及余额复用。离线证据不等同于 Android OCR 引擎、空位像素阈值及完整实机流程验证。
